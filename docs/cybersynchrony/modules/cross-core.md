# CROSS-CORE

CROSS-CORE focuses on secure cooperation and information exchange during cyber incidents. Public CYberSynchrony material also discusses integrity mechanisms that can help detect whether shared records have changed.

## What This Means For NIS2COMPASS

NIS2COMPASS uses the CROSS-CORE role to explain evidence packaging, hashes, controlled exchange, and traceable review. A hash or integrity record can help show that a file changed.

> An integrity record cannot prove that the original file was true, lawfully collected, complete, written by a particular person, legally admissible, or sufficient for NIS2 compliance.

## Selected Tool

Selection note: 28 October 2026.

The Blockchain Integrity Validator is selected for a conditional evaluation using synthetic, or made-up, evidence only. It is relevant to evidence consolidation. The expected output is a check indicating whether the tested file's bytes have changed.

> The evaluation remains conditional on confirmed interface and documentation. No raw pilot evidence is to be placed on a blockchain. Selection does not establish deployment or a completed evaluation. See the [eight-tool selection and conditions](../selected-tools.md).
